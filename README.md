# SERAMIKCIM

SERAMIKCIM portable paketleri ve otomatik güncelleme bilgisi (`latest.json`).

**İndirme:** [Releases](../../releases/latest) sayfasından `SERAMIKCIM-<sürüm>-portable.zip` dosyasını indirin, kendi kullanıcı klasörünüze (`C:\Users\<ad>`) çıkarın ve `SERAMIKCIM\SERAMIKCIM.exe`yi açın. Yönetici şifresi gerekmez.

Kaynak kod bu depoda değildir.
